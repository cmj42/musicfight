# MusicFight — 体感音游 MVP（手感测试版）

跟着逼近的发光球出拳的横版 RPG+音游。这一版只为一件事：**亲手验证摄像头延迟/判定到底跟不跟手**。

## 怎么跑

**方法 A（最简单）**：双击 `index.html`，用 Chrome 打开 → 点「点击开始」→ 允许摄像头。
首次会联网下载 MediaPipe 模型（几秒）。

> 如果摄像头或技能测试 MIDI 被浏览器拦截（部分系统对 `file://` 限制），用方法 B。

**方法 B（本地服务器，最稳）**：在本文件夹里开终端运行其一，然后浏览器访问 `http://localhost:8000`：
```bash
python -m http.server 8000      # 有 Python
# 或
npx serve .                     # 有 Node
```

技能战斗测试会优先从 `assets/skill_battle_test.mid` 读取 MIDI 触发轨；如果 `file://` 阻止读取文件，会自动使用内置 MIDI 事件兜底，不再退回纯节拍器。

需要：能联网（下模型）+ 带摄像头 + Chrome/Edge（推荐）。

## 现在这一版：出拳判定测试（默认）

打开就是「判定测试」模式——**先不管敌人和节奏，只确认"出拳就触发对应颜色光柱"跟不跟手**。

- 上半身入画，站到能看清两条手臂的距离。
- 推荐**平拳**：左手向右挥、右手向左挥（横向动作摄像头看得最清，比正对镜头的直拳准得多）。左手亮<蓝光柱>，右手亮<红光柱>。
- 屏幕**中央有两根实时强度柱**（蓝=左、红=右）。柱子涨过**黄色虚线(阈值)**就触发一次。

快捷键：`D` 调试叠加 · `Space` 暂停 · `R` 重开。

### 触发不了 / 乱触发，就调这几个（右上角 ⚙）

- **灵敏度(阈值)**：看中央柱子——静止时柱子大概到哪，把阈值设在它**之上一点**。触发不了→调低；乱触发→调高。
- **平滑(防抖)**：现在用的是自适应滤波（静止时狠狠平滑、出拳时几乎不平滑），所以**调小更稳但基本不增加延迟、收拳柱子也会马上落下**。还嫌抖就调小，嫌钝就调大。
- **出拳信号**：
  - `挥动速度(xy)`（默认）= 看手在画面里的移动，**平拳/钩拳最准**。
  - `向前/深度(z)` = 专测正对镜头的直拳；z 本身较抖，仅作对比。
  - `自动` = 两者取较大，最容易触发但也最容易被 z 噪声误触。
- 底部实时数字 `img a/b · z a/b` = 两手的挥动/向前信号值，帮你判断用哪个信号。

调到跟手后，⚙ 里把「判定测试」切到**关**，就进完整游戏（敌人球+血条）。

### 提高识别准确度（环境最关键）

1. **打好光**：脸/身体正面要亮，**别背光**（身后别有窗户或强光），这条比调任何参数都管用。
2. **站够远**：上半身 + 两条挥动的手臂都要在画面里，别只拍到脸。
3. **背景干净**、衣服和背景有对比；别穿太宽松的袖子（手腕要看得见）。
4. **摄像头大致与肩同高、放平**。
5. 关掉后台占资源的程序，**帧率越稳越准**（右下角能看到 FPS / 检测耗时）。

### 完整游戏模式的其他参数

- **校准(ms)**：总判「晚了」→ 调小；总判「早了」→ 调大。推荐直接用 ⚙ 里的 **🥁 节拍校准向导**：跟着节拍器打 10 拳，自动测出中位延迟并写入校准。
- **球速 / 判定窗**：休闲手感就把判定窗放宽、球速放慢。

### 判定区（2026-07 重做）

- 战斗画面**中央**有一条发光判定区：**金圈 = Perfect 窗（±120ms）**、蓝圈 = Good 窗（±280ms），随节拍呼吸。**球心进金圈时出拳 = PERFECT**。
- 判定改为**纯时间窗**（对称、可校准）：窗内才有节奏分和连击；**窗外任何还没砸到你的球都能「拦截」**（含已 MISS 正飞向你的、以及刚出生的）——球被打掉不会伤到你，+40 保底分，但不涨也不断连击。场上不留残球，前面漏一个不会挡住后面踩拍；抢分和连击还得跟着音乐打。
- 攻击时刻直接取自 BGM 鼓点并**吸附到八分音符网格**，曲速也从 MIDI 文件实时读取——理想出拳时机永远踩在音乐上。选点按**重音打分**（底鼓/军鼓/镲优先、力度加权、正拍加分）：强重音允许更密、弱拍更疏，攻击频率跟着音乐的重音骨架起伏。
- **球速倍率**（⚙ 节奏区）：默认 0.75，越小球越快、中央判定区画得越宽（时间窗不变，更好读），反应时间变短；飞行时长永远吸附整数拍（下限 2 拍）。嫌难调大，嫌宽度不够调小。
- 漏掉的球会继续飞向左侧的你，砸中才掉血；伙伴自动技能（余震/回写/熔断/补帧/超频）会在战斗中按条件自动触发（青色提示）。余震=连击每满 10（10/20/30…）补一击（敌方总血 5%，跨章节保值）；剧情掉落：一章余震、二章回写，熔断为备用模块（暂无掉落）。
- **对话有 BGM 了**：过场/自检/教学阶段播放程序化生成的循环环境声，每章不同主题（序章·内网机房冷鸣 / 一章·都市雨夜 / 二章·自由地拨弦 / 自我探索·心跳微光），停留多久都不会断；进战斗自动让位给战斗 BGM。战斗合成器混音也重配平：技能轨"叮"声压低，鼓/贝斯抬高，拍子更压得住场。

### 高/中/低/左/右 怎么判（四条判定线 + 轨迹起点）

判定不看"手停在哪"，而看**一拳从哪起、到哪止**：**起点必须在身体中间的方框内，终点越过某条线**才算数。打开「调试 ✓」就能在右下角摄像头画面里看到这四条线（都可调）：

- **高线 ↑ / 低线 ↓**（金色横线）：终点越过上面=高拳，越过下面=低拳。
- **左手线 →**（蓝，在中线**偏右**）：左手平拳要从中间挥过它。
- **右手线 ←**（红，在中线**偏左**）：右手平拳要从中间挥过它。
- **过线必须** 开关：关掉则任何快速挥拳都算（不要求过线/起点）。
- **起点只要在高线与低线之间**(纵向中段)即可，左右不限——左手可从左侧、右手可从右侧起手挥过去。起点不在此区间→「× 起点不在高低之间」，没过线→「× 未过线」。
- 上下、左右两个方向都做了平滑滤波（自适应 One Euro），起点和终点用的都是平滑后的位置。
- 命中时游戏区对应那一路(高/中/低)整条色带发光 + 「左 L · 高 HIGH」字样，方便核对。

## 已知边界（MVP）

- `向前出拳` 用的 z 深度较抖；默认用 `挥动速度` 更可靠，z 模式留作对比。
- 球的生成是固定 BPM 节拍网格（不是按歌曲真实节奏的谱面）——验证手感够用。
- 还没有：大招、攻击/回血技能、多敌人、打包成 exe/app。手感过关后再上。
